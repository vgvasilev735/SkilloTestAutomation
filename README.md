# Skillo Test Automation

Този проект представлява автоматизирана система за UI тестване на платформата **Skillo** – социална мрежа за споделяне на постове, подобна на Instagram.

Проектът използва **Selenium WebDriver**, **TestNG** и **Maven**, организиран по модела **Page Object Model (POM)** за по-добра поддръжка и мащабируемост.

---

## Какво тестваме?

- Успешен вход с валидни потребителски данни
- Създаване на нов пост със снимка и описание
- Промяна на статуса на пост (Public/Private)
- Проверка дали новият пост се появява в профила на потребителя

---

## Технологии

- Java 11
- Selenium 4
- TestNG
- WebDriverManager
- Maven

---

## Структура на проекта

```
src/
 └── test/
     ├── java/
     │   ├── pages/         # Класове с Page Object Model
     │   └── tests/         # Тестови класове с TestNG
     └── resources/         # Тестови изображения и други файлове
```

---

## Как се стартира

1. Клонирай проекта:
   ```bash
   git clone https://github.com/vgvasilev735/skillo-test-automation.git
   cd skillo-test-automation
   ```

2. Стартирай тестовете с Maven:
   ```bash
   mvn test
   ```

> Увери се, че имаш инсталиран **Java 11+** и **Maven**.

---

## Допълнителна информация

- Тестовете използват WebDriverManager за автоматично управление на драйверите.
- Всеки тест симулира реален потребителски сценарий.
- Изображенията за постовете се намират в папката `src/test/resources`.
